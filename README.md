# Cyber Threat Analytics

Учебный проект по анализу данных о киберинцидентах с использованием Python и Pandas.

## О проекте

Проект предназначен для анализа учебного набора данных о киберинцидентах. В рамках работы исследуется распределение угроз, уровень критичности инцидентов и средний показатель риска по различным типам угроз.

## Основные задачи

* Загрузка и обработка данных из CSV
* Анализ распределения типов киберугроз
* Исследование уровня критичности инцидентов
* Расчёт среднего показателя риска
* Группировка данных по категориям угроз
* Построение аналитических графиков
* Формирование выводов на основе данных

## Технологии

* Python 3
* Pandas
* Matplotlib

## Структура проекта

```text
cyber-threat-analytics/
├── data/
│   └── incidents.csv
├── results/
├── analysis.py
├── requirements.txt
└── README.md
```

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить анализ:

```bash
python analysis.py
```

## Результат

Скрипт выводит основные статистические показатели, определяет наиболее распространённые типы угроз и сохраняет графики в папку `results`.

Проект выполнен в учебных целях для развития навыков анализа данных и применения Python в задачах информационной безопасности.
